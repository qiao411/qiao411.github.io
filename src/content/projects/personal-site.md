## 项目概述

基于 Astro 构建个人网站并部署于 GitHub Pages，用于展示个人经历、AI 产品项目和实践成果。

## 实践内容

- 使用 Trae 与 AI Coding 工具辅助页面布局、组件开发和样式优化。
- 探索通过 Skills 将结构化文档内容转为网页代码，提升内容更新与复用效率。
- 完成静态站点构建、部署配置与问题排查。
